# Página Web Personal - Taller Práctico HTML

Este repositorio contiene la estructura básica de una página web personal en HTML, desarrollada para la asignatura **Diseño de Sistemas en Internet**.

## 🚀 Contenido del Proyecto
- **`index.html`**: Estructura principal de la página que incluye:
  - Encabezado con mi nombre.
  - Párrafo de presentación personal.
  - Foto/Imagen representativa.
  - Lista de habilidades e intereses.
  - Enlaces a redes sociales y sitios de interés.

## 🛠️ Tecnologías Utilizadas
- HTML5
